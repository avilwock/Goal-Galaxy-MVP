# Goal-Galaxy

## Description

This purpose of this project is to create a personal planner and goal setting application. The user will be able to track their day to day to-do lists, and set up goals to meet regarding specific activities. This project was created because I would like a reliable way to track my personal progress in regards to several goals, which are self-paced and self-reliant that they get done.

This tracker will have multiple sections.

The first will have the capability to create goals for yourself regarding specific activities you wish to improve in, ie: exercise and fitness, language learning, instruments, drawing, etc. The purpose is mainly for those that are accountable to themselves for progress tracking. Instead of an instructor gauging them, this specific goal tracker is designed for people to set their individual goals at a rate of weeks, months, and even years. You will set the goal for the year at the start of creating the goal, and then work towards that goal with smaller goals set in between to reach that level.

The second section is the activity tracker. Here, you will be able to record how you've done on your activity, length of time spent, progress, and notes about how you did.

There will be a journaling section where you can journal. The date will be default set to the day, but will allow for the user to change it to an actual personalized title if they wish.

A to do list will also be placed within the person's dashboard for the day, with the option to open a full monthly or weekly calendar to view and add information as needed. The tasks will be set with priority rankings and potential deadlines as well.
